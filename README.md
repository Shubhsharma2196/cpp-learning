📐 Hypotenuse Calculator
A simple console application that calculates the hypotenuse of a right-angled triangle using the Pythagorean theorem ($a^2 + b^2 = c^2$).

---> How to Run
1. Open your terminal or command prompt.
2. Compile the file using a C++ compiler:
   ```bash
   g++ "Hypotenuse Calculator project.cpp" -o calculator
   ```
3. Run the executable:
   * **Windows:** \calculator.exe``
   * **Mac/Linux:** \./calculator``
