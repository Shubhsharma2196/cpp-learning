# Console Calculator

A simple console-based calculator made in C++ as part of my C++ learning journey.

## Features

* Addition `+`
* Subtraction `-`
* Multiplication `*`
* Division `/`
* Takes two numbers from the user
* Uses a `switch` statement to select the operation
* Displays the calculated result

## Concepts Practiced

* Variables
* `double` and `char`
* `std::cin` and `std::cout`
* `switch` statements
* `case`, `break`, and `default`
* Arithmetic operators
* Basic console input/output

## Example

```text
******************CALCULATOR******************
Enter either (+ - * /): *
Enter Num1: 10
Enter Num2: 5
Result: 50
************************************
```

## About

This is a beginner C++ practice project created while learning C++.
